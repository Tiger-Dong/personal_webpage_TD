202605.26-08.08

Arduino + Michelson Interferometer

System developer · Beijing Jiaotong University系统开发 · 北京交通大学

A prototype control module for a Michelson interferometer that accepts voice and text instructions for selected adjustment tasks.面向迈克耳孙干涉仪的原型控制模块，可通过语音与文字指令完成部分调节任务。

Problem问题

Optical alignment depends on small, repeated manual motions. That can make operation difficult for new users and for people with limited hand mobility.光学调节依赖细微、重复的手动操作，对初学者和手部活动受限的使用者均可能构成障碍。

My Role我的职责

I developed the control workflow, integrated six motorized channels for coarse, fine, and two-axis mirror adjustment, and designed compact adapters and stabilizing brackets.我开发控制流程，集成六路电机以完成粗调、细调与镜面双轴调节，并设计紧凑的转接件和稳定支架。

Technical Approach技术路径

ArduinoStepper MotorsSpeech RecognitionLLM Command Parsing3D Printing

Before motion, the system checks the requested target and movement parameters and rejects unclear commands.系统会在运动前检查目标与运动参数，并拒绝含义不明确的指令。

Evidence公开证据

Watch system demonstration观看系统演示Watch component demonstration观看组件演示

Result结果

The prototype provides voice and text control for selected adjustment tasks. By simplifying the bracket geometry and print settings, I reduced one bracket's print time from about three hours to sixteen minutes, enabling faster fit-testing iterations.该原型已能以语音和文字控制指定调节任务。通过简化支架结构并调整打印参数，我将单个支架的打印时间从约三小时缩短至十六分钟，便于更快地进行装配测试与迭代。

Weather & Location Planning Assistant天气与地点规划助手

Independent developer · United States · Repository: agent_service独立开发 · 美国 · 仓库：agent_service

A lightweight local-model workflow that combines natural-language questions with weather and geocoding utilities.将自然语言提问与天气、地理编码工具结合的轻量本地模型工作流。

My Role我的职责

I independently designed the query flow, connected the model with weather and location modules, and transformed returned data into user-facing clothing and trip-preparation suggestions.我独立设计查询流程，将模型与天气、地点模块连接，并把返回数据转化为穿着和出行准备建议。

Technical Approach技术路径

OllamaQwen3GeocodingWeather APIBilingual Input

The workflow handles mixed Chinese-English questions, identifies a place, retrieves coordinates and forecast data, then composes a practical response.该流程可处理中英文混合提问，识别地点、查询经纬度与天气预报，并生成实用回复。

Evidence公开证据

Result结果

The completed prototype turns a single natural-language request into location context, weather information, and a concise preparation suggestion.完成的原型可将一次自然语言请求转化为地点信息、天气数据和简洁的出行准备建议。

202405.18-08.10

Polyurethane Simulation Platform聚氨酯材料模拟平台

Frontend developer · Beijing Jiaotong University前端开发 · 北京交通大学

A frontend for a material-simulation workflow supporting formulation studies for railway elastic pads.服务于铁路弹性垫板配方研究的材料模拟工作流前端。

Problem问题

A simulation backend is difficult for non-programming material specialists to use directly when entering formulations, tracking tasks, and comparing outputs.材料专业人员若直接使用模拟后台，在输入配方、跟踪任务和比较结果时会面临较高使用门槛。

My Role我的职责

I developed frontend pages for task creation, task management, and result details, connected them to the simulation backend, and refined the material-input experience.我开发任务创建、任务管理和结果详情页面，将其连接到模拟后台，并完善材料输入体验。

Technical Approach技术路径

Frontend DevelopmentForm ValidationTask ManagementChartsSearch

The interface uses table-based formulation input, three-decimal precision, constrained fields, searchable time-ordered records, progress updates, charts, and result tables.界面采用表格式配方输入、三位小数精度和字段约束，并提供可检索的时间排序记录、进度更新、图表和结果表格。

Evidence公开证据

View public frontend repository查看公开前端仓库

Internal design documents, registration files, and collaboration materials are intentionally not published.内部设计文档、登记文件和合作材料均不在本站公开。

Result结果

The frontend gives users a structured path to enter formulations, submit calculations, monitor progress, and compare simulation results before arranging physical trials.该前端为用户提供了输入配方、提交计算、监控进度和比较模拟结果的结构化流程，帮助在安排实体试验前完成初步比较。

202306.01-08.10

Wolf-Sheep Collective Behavior Simulation狼羊群体行为模拟

Independent developer · United States独立开发 · 美国

A Python simulation inspired by research on collective predation and escape.受群体捕食与逃逸研究启发而完成的 Python 仿真项目。

Problem问题

Research on collective pursuit and escape describes interactions that are difficult to understand from equations and figures alone.群体追逐与逃逸研究中的互动关系，单靠公式和论文图表不易直观理解。

My Role我的职责

I independently translated paper concepts into a configurable program, implemented the interaction rules, and maintained logging and component tests for the model.我独立将论文概念转化为可配置程序，实现交互规则，并为模型保留日志和组件测试。

Technical Approach技术路径

PythonAgent-Based ModelingLoggingComponent Tests

The model includes movement, neighborhood alignment, repulsion, pursuit, and escape rules with adjustable parameters.模型包含移动、邻域对齐、排斥、追逐和逃逸规则，并允许调整参数。

Evidence公开证据

View source code on GitHub在 GitHub 查看源代码Read the research paper阅读参考论文

Result结果

The program makes it possible to vary local interaction rules and observe changes in simulated group behavior, connecting scientific reading with a testable implementation.该程序可以改变局部交互规则并观察模拟群体行为的变化，将论文阅读与可测试的实现连接起来。
